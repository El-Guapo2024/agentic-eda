# Footprint Editor parity with KiCad pcbnew's footprint editor

One row per footprint-editor action, its status, and the KiCad file it
came from. Follows the same status vocabulary `PARITY-pcb.md`/
`PARITY-sch.md` use: **identical** (same logic/constants, browser-platform
adaptations noted inline), **partial** (core behavior ported, a real gap
noted), **missing** (not started).

KiCad source snapshot: the read-only checkout at the path the task gave
this session (`pcbnew/` as of its own commit; this file does not re-derive
that commit hash -- see `PARITY-pcb.md`'s own header for how the project
usually records it, not repeated here since this session's snapshot path
was scratch, not the tracked mirror).

Ported logic lives in `web/studio/src/kicad-port/padNumbering.ts` (unit
tested, `npm run test:unit`) and `crates/model/src/ir.rs` (Rust unit
tests, `cargo test -p eda-model`) -- the two are deliberately the same
algorithm so a client-side preview can never disagree with the backend's
authoritative answer; see `padNumbering.ts`'s own header comment.

## 8. Library tree and the footprint tool groups (`pcbnew.ModuleEditor.*`, `pcbnew.PadTool.*`)

The Footprint tab has KiCad's library tree (`FOOTPRINT_TREE_PANE`) with the context menu `FOOTPRINT_EDITOR_CONTROL::Init` builds (an entry
that needs an unported subsystem is listed dimmed, "not ported yet"), and its own menu bar: `pcbnew/menubar_footprint_editor.cpp`
extracted into `src/kicad/fp_menus.json` by `tools/extract-lib-editor-menus.js` (the tab used to show the board editor's menu).
The studio's library is the project library (`design.footprint_library`): a footprint the tree shows that only the intent, a library
file or the built-in table defines is read-only until it is opened (which makes an editable copy). Copy, Export and Duplicate read any
footprint (`GET /api/library/footprint`); Delete and Rename need a project entry. 45 of the 61 actions of the two library editors
in `docs/parity/UI-ACTIONS.md` are wired by this batch; the other 16 carry a recorded reason.

The frame is KiCad's (`footprint_edit_frame.cpp`): its three icon toolbars (top, left options, right drawing) are `pcbnew/toolbars_footprint_editor.cpp`
extracted into `src/kicad/fp_toolbars.json` by `tools/extract-editor-toolbars.js`, each button with its KiCad icon (`tools/lib/toolbarIcons.test.js`
fails when one has none); a button whose action needs a subsystem this studio lacks (the footprint wizard, the Properties pane; mirror, group and the rest until section 20) is dimmed with
its reason (`src/kicad/editor_toolbar_support.json`). The library tree is a column at the far left that folds to a handle. With nothing open the canvas is
empty, with its grid and a hint, as KiCad's is.
